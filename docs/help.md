# Help

The page the help icon in Raven opens. It covers setup, tasks, answering
and signing, and keeps the rules the app no longer repeats on screen.

## Set up

Open Settings and follow the four cards: connect your coding agent over
MCP, give Raven context (GitHub or a local clone), connect Slack if you
want links sent there, and invite the people who decide. The "Not set up
yet" list at the top of Settings names what is still missing; outside
Settings the same state is one dot on the Settings nav item. MCP
connections do not require the local launcher. See [Getting
started](getting-started.md) and the [technical reference](reference.md).

## Follow a task

Tasks lists what each agent registered and who each task waits on. Open
one for its goal, the questions waiting on a person, what was decided,
the notes left for the agent and the full history.

Task status records workflow state; it does not prove an external coding
agent is running.

Requester is recorded task context, not proof of identity.

## Answer and sign

The inbox holds the decisions waiting on a person. Answer, sign, or hand
on to someone better placed. A found answer still needs its owner's
signature unless an enabled standing rule covers it.

Evidence is context. Explicit sign-off authorizes a decision.

Recording a new or corrected answer retires the existing standing rule. A
sign-off with unchanged answer and sources keeps it.

A correction is a signed answer; every decision that leaned on the old
answer is marked for review.

Transcripts are context, never a participant's approval. Recording
requires an explicit consent record.

## Links from Slack

A Slack message links to a personal task page for the person it names.
A link does not grant access. See [Slack](slack.md) and
[Identity](identity.md).
